# バレー スコアボード (プロトタイプ)

中学校バレーボール部向けの、試合中にその場で得点をつけるためのスコアボードです。
タブレット／スマホのブラウザで動きます。インターネット接続がなくても動作します。

## 公開URL（誰でも使えるWEBアプリにする）

GitHub Pages で、Claudeアカウント不要・ネットさえあれば誰でも使える公開URLにできます。
リポジトリ設定で **1回だけ** 有効化するだけです（管理者操作のためコード側では自動化不可）：

1. GitHub の `kjn1989/v-app` → **Settings** → 左メニュー **Pages**
2. **Build and deployment** の **Source** を **「Deploy from a branch」** に
3. **Branch** を **`claude/volleyball-scoring-app-6k86ny`** ／ フォルダ **`/ (root)`** にして **Save**
4. 1〜2分で公開: **https://kjn1989.github.io/v-app/**

以後このブランチへ push するたびに自動で更新されます。

## 使い方

`index.html` をブラウザで開くだけでも動きます（インストール不要・アカウント不要）。

### 基本の得点入力
- **左右のパネルをタップ = そのチームに +1点**
- **−1**: 押し間違いをその場で修正
- **取り消し (↶)**: 直前の操作を丸ごと元に戻す（何回でも）
- **T/O**: タイムアウト（1セット2回まで、残り回数を表示）
- **🏐 サーブ切替**: サーブ権の表示を切り替え（得点した側に自動でつきます）
- **⚙ 設定**: チーム名 / 試合形式（1・3・5セットマッチ）/ 試合リセット

### 選手登録とスタッツ（1画面で完結）
- **👥 選手**: 背番号と名前を登録（ホーム／アウェイそれぞれ）
- 選手を登録すると、得点側をタップした時にパネルが開き、**得点理由を2グループで記録**（視点の混線を排除）：
  - **① 自チームのプレーで得点**：スパイク / ブロック / サービスエース → 背番号を選ぶ（2タップ）
  - **② 相手のミスで得点**：相手のスパイクミス / 相手のサーブミス / 反則・その他
  - 慌ただしい時は **「得点のみ（記録なし）」** で1タップ即入力
- **合わせ技（得点＋配球を同時記録）**：設定の「配球（方向）も記録する」がONのとき、
  - **サービスエース・スパイク・ブロック** を選ぶと、そのまま **配球記録画面（フルのコート）** が開き、
    **だれが・どこから→どこへ**（ブロックは左/中/右）を選ぶと **得点と配球を同時に記録**
  - **相手のミス／得点のみ**は場所なしで即入力。OFFにすれば全部そのまま即入力（テンポ優先）
- **逆方向も連動**：🏐配球画面での記録も得点に反映（サーブ=エース/ミス、スパイク=決定/被ブロック/ミス、
  ブロック=得点）。取り消しは得点も配球もまとめて戻ります（二重入力なし）
- **得点の経過（1点ずつ）**：📊スタッツ と 試合結果 に、何点目が何で入ったかを両チーム分、
  積み上げで表示（自軍=左/相手=右で色分け）
### プレー記録バー（トップ画面の下1/3）— 成功率・有効率・A/B/C/D・ディグ用
得点にならなかったプレーも1本ずつ記録して、率を出します。
- **サーブ**：どこから→どこへ＋エース/効果/成功/ミス → 成功率・有効率・エース率
- **レセプション**：相手のサーブ位置＋**A/B/C/Dパス**（基準はコーチの判断でタップ）→ A率・返球率
- **スパイク**：位置→コース＋種類＋決定/効果/被ブロック/ミス/拾われた → 決定率・有効率
- **ディグ**：相手の攻撃の起点→拾った位置＋有効/上げた/失点 → 有効率・失点率
- **ブロック**：位置（左/中/右）＋得点/ワンタッチ/抜かれ → 得点率
- 終端プレー（エース・決定・ブロック得点・ディグ失点等）は得点にも自動反映。取り消しで一括

- **📊 スタッツ**（3つのビュー）
  - **得点**：選手別の 得点 / 決定率 / 決定 / ミス / ブロック / エース / サーブ失。**行をタップで個人詳細**
  - **配球**：サーブ／レセプ／スパイク／ディグ／ブロック別に、選手別の率（成功率・有効率・A率・失点率 等）＋ヒートマップ
  - **経過**：得点の経過（1点ずつ・両チーム色分け）
- 選手未登録のチームは、これまで通りタップで即得点

> 設計メモ: 意味を持つ色（成功=緑／ミス=赤／効果=琥珀／タイトル=金）、分母0は「-」表示、
> 記録の主導権は常にユーザー（自動終了は提案のみ）——姉妹アプリ AIBSS(AI-BASE) の
> 操作思想を踏襲。データはイベント記録型で、通算・大会単位の集計にも拡張しやすい構造。

### 配球記録（コート・ゾーン／9分割グリッド）
- **🏐 配球**: コートを俯瞰した2面（自コート・相手コート）を9分割（前/中/後×左/中/右）で表示。
  上部でスキル切替（**サーブ / スパイク**）
- **サーブ**：サーバー → ①自コートのサーブ位置 → ②相手コートの狙い → 結果（エース/効果/成功/ミス）
  - 集計：本数・成功率・有効率・エース率・ミス＋狙った場所のヒートマップ
- **スパイク**：アタッカー → 攻撃の種類（オープン/A・B・C・Dクイック/バックアタック/二段）
  → ①打った位置 → ②相手コートのコース → 結果（決定/被ブロック/ミス/つながれた）
  - 集計：本数・決定率・決定・被ブロック・ミス・つながれた＋打ったコースのヒートマップ
- ※ブロック／ディグ／レセプション(A/B/C/Dパス)を同じコートUIで順次追加予定

### 履歴・共有
- **📋 履歴**: 終わった試合を自動保存、一覧・詳細で見返し、個別削除
- 試合終了画面／履歴から **結果を画像で共有**（スマホはLINE等へ、PCはダウンロード）。最多得点の選手も画像に入ります

## 対応しているルール（現状）

- ラリーポイント制（どちらのサーブでもラリーに勝てば得点）
- 各セット25点先取、2点差がつくまで継続（デュース）
- 最終セット（デシディングセット）は15点先取、8点でコートチェンジの案内を表示
- セット先取数で勝敗判定（3セットマッチ=2セット先取、5セットマッチ=3セット先取）
- 試合の状態はブラウザに自動保存（誤ってリロードしても続きから）

## これから（コート記録の拡張）

配球記録の土台（9分割グリッド＋サーブ）ができました。同じコートUIで順次追加します：

- **アタック**：どこから→どこへ・攻撃の種類 → 決定率／得点率／有効率
- **ブロック**：ブロックした場所＋相手の攻撃（どこから→どこへ）
- **レセプション**：A/B/C/Dパスの4段階
- **ディグ**（アタックのレシーブ）：有効率・失点率（相手の攻撃の起点も記録）
- 配球記録とスコア入力の統合（二重入力をなくす）／ローテーション・交代・リベロ

これはたたき台です。手書きスコアシートの実物（特にゾーンの呼び方・A/B/C/Dパスの基準）を
見せてもらえると、現場に合わせて精緻化できます。
