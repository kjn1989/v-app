# バレー スコアボード (プロトタイプ)

中学校バレーボール部向けの、試合中にその場で得点をつけるためのスコアボードです。
タブレット／スマホのブラウザで動きます。インターネット接続がなくても動作します。

## 使い方

`index.html` をブラウザで開くだけです。インストール不要・アカウント不要。

### 基本の得点入力
- **左右のパネルをタップ = そのチームに +1点**
- **−1**: 押し間違いをその場で修正
- **取り消し (↶)**: 直前の操作を丸ごと元に戻す（何回でも）
- **T/O**: タイムアウト（1セット2回まで、残り回数を表示）
- **🏐 サーブ切替**: サーブ権の表示を切り替え（得点した側に自動でつきます）
- **⚙ 設定**: チーム名 / 試合形式（1・3・5セットマッチ）/ 試合リセット

### 選手登録とスタッツ（1画面で完結）
- **👥 選手**: 背番号と名前を登録（ホーム／アウェイそれぞれ）
- 選手を登録すると、得点側をタップした時に小さなパネルが開き、
  **「スパイク／ブロック／サーブ」→ 背番号** の2タップで、誰の得点かを記録
- 慌ただしい時は **「相手のミスで得点」「得点のみ（記録なし）」** で1タップ即入力
- **📊 スタッツ**: 選手ごとの 得点／スパイク／ブロック／サーブ得点 を自動集計（登録した選手に紐づく）
- 選手未登録のチームは、これまで通りタップで即得点

### 履歴・共有
- **📋 履歴**: 終わった試合を自動保存、一覧・詳細で見返し、個別削除
- 試合終了画面／履歴から **結果を画像で共有**（スマホはLINE等へ、PCはダウンロード）。最多得点の選手も画像に入ります

## 対応しているルール（現状）

- ラリーポイント制（どちらのサーブでもラリーに勝てば得点）
- 各セット25点先取、2点差がつくまで継続（デュース）
- 最終セット（デシディングセット）は15点先取、8点でコートチェンジの案内を表示
- セット先取数で勝敗判定（3セットマッチ=2セット先取、5セットマッチ=3セット先取）
- 試合の状態はブラウザに自動保存（誤ってリロードしても続きから）

## これから相談しながら詰めたいこと

- **決定率**: ミス（スパイクミス・被ブロック・サーブミス）も記録して決定率・成功率を出す
- **レセプション**: サーブレシーブの返球精度（A/B/Cパス）
- ローテーション・選手交代・リベロの扱い（公式記録に近づける）
- 中学の大会規定に合わせた点数・セット設定
- 手書きスコアシートの実物に合わせた項目調整
