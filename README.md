# バレー スコアボード (プロトタイプ)

中学校バレーボール部向けの、試合中にその場で得点をつけるためのスコアボードです。
タブレット／スマホのブラウザで動きます。インターネット接続がなくても動作します。

## 使い方

`index.html` をブラウザで開くだけです。インストール不要・アカウント不要。

- **左右のパネルをタップ = そのチームに +1点**
- **−1**: 押し間違いをその場で修正
- **取り消し (↶)**: 直前の操作を丸ごと元に戻す（何回でも）
- **T/O**: タイムアウト（1セット2回まで、残り回数を表示）
- **🏐 サーブ切替**: サーブ権の表示を切り替え（得点した側に自動でつきます）
- **⚙ 設定**: チーム名 / 試合形式（1・3・5セットマッチ）/ 試合リセット

## 対応しているルール（現状）

- ラリーポイント制（どちらのサーブでもラリーに勝てば得点）
- 各セット25点先取、2点差がつくまで継続（デュース）
- 最終セット（デシディングセット）は15点先取、8点でコートチェンジの案内を表示
- セット先取数で勝敗判定（3セットマッチ=2セット先取、5セットマッチ=3セット先取）
- 試合の状態はブラウザに自動保存（誤ってリロードしても続きから）

## これから相談しながら詰めたいこと

- 用途の方向性: ①コート脇の得点表示に特化 / ②公式記録用紙に近い詳細記録 / ③選手ごとのスタッツ（サーブ成功率など）
- ローテーション・選手交代・リベロの扱い
- 中学の大会規定に合わせた点数・セット設定
- 試合結果の保存・共有（PDF・画像・一覧）
